# Training data

The dataset is intentionally not duplicated in this repository.

Download the **Dynamically Generated Hate Speech Dataset** from its
[official repository](https://github.com/bvidgen/Dynamically-Generated-Hate-Speech-Dataset).
The project originally used the 40,623-example release described by Vidgen et
al. (ACL-IJCNLP 2021).

The dataset is licensed separately under CC BY 4.0 and contains synthetic
hateful language that may be distressing to inspect.
